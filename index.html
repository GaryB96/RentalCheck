PEI Mutual Residential Rental Inspection

Prince Edward Island — Existing Residential Rental Buildings

Current reference standards: NBC (2020) · NFC (2020) · CEC (2024) · NPC (2020) · NFPA 1 (2024) · NFPA 101 (2024)

Technical codes and standards that may be referenced:

  • National Building Code of Canada 2020 (NBC 2020)
  • National Fire Code of Canada 2020 (NFC 2020)
  • National Plumbing Code of Canada 2020 (NPC 2020)
  • Canadian Electrical Code, Part I, 2024 (CEC 2024)
  • NFPA 1 Fire Code (2024)
  • NFPA 101 Life Safety Code (2024)
  • CSA B139 — Oil-burning equipment
  • CSA B149.2 — Propane-burning appliances/equipment
  • CSA B365 — Solid-fuel-burning appliances/equipment

PEI legislation: Residential Tenancy Act; Public Health Act — Rental Accommodation Regulations; Fire Safety Act and Fire Safety Regulations.

Important: Current codes are reference standards where applicable. An existing building is not necessarily required to comply retrospectively with every provision that applies to new construction. Use R — Further Review Required where applicability cannot reasonably be determined during the visual inspection.

Foundation / Below-Grade Space

Crawl Space Details

Inspector Guidance

Record observed height and use rather than assuming every low space is a crawl space. Use R where classification is uncertain.

Code Reference

NBC 2020 contains crawl-space provisions in Parts 3 and 9. For certain Part 3 purposes, conditions such as height over 1.8 m, occupancy, passage of flue pipes, or use as a plenum can affect treatment of the space.

Building Fire Alarm System — Applicability Guide

Enter storeys and dwelling units in Section 1.
Rule Used by This Tool

For an existing apartment building, the NFPA 101 Chapter 31 general screening trigger used here is 4 or more storeys OR more than 11 dwelling units. Exceptions can apply based on separation and independent exits.

Automatic Sprinkler System — Applicability Guide

Do not assume every existing multi-unit rental requires sprinklers. Existing-building requirements depend on occupancy and building characteristics.
Inspector Guidance

For an ordinary existing low-rise apartment building, “No sprinkler system observed” should not automatically receive D. Use R when characteristics suggest further review.

Portable Fire Extinguishers — Applicability Guide

Do not apply a blanket rule that every individual apartment must contain a portable fire extinguisher.
